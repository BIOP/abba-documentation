# Installation

:::{warning}
**This page is being reworked for ABBA 0.24.** More detailed installation instructions will follow soon.
:::

For the moment, all you need is an up-to-date Fiji with the `Unige-Biochem` update site activated: it brings everything ABBA needs.

1. If Fiji is not installed yet, download it from [fiji.sc](https://fiji.sc/) and install it. Otherwise, update it with {menuselection}`Help --> Update...`.
2. Click {menuselection}`Help --> Update... --> Manage update sites`, tick the `Unige-Biochem` update site, then click `Apply and close` and `Apply changes`.
3. Restart Fiji.

elastix, DeepSlice and BrainGlobe are installed automatically by ABBA the first time they are used: this requires an internet connection and takes a few minutes.
