# Keyboard & mouse shortcuts

On macOS, use `cmd` instead of `ctrl`.

## Viewer navigation

| Shortcut | Action |
|---|---|
| `hold and drag right-click` | Pan across the image. |
| `mouse wheel` | Zoom in / out. |
| `up / down keys` | Zoom in / out. |
| `shift + up / down keys` | Fast zoom in / out. |
| `C` | Center the view on the current slice. |
| `Right` / `Left` | Make the next / previous slice the current slice. |
| `R` | Switch between the positioning and the review modes. |

## Slice selection

| Shortcut | Action |
|---|---|
| `hold and drag left-click` | Draw a rectangle to select the slices inside it. |
| `shift + hold and drag left-click` | Add slices to the current selection. |
| `ctrl + hold and drag left-click` | Remove slices from the current selection. |
| `ctrl + A` | Select all slices. |
| `ctrl + shift + A` | Deselect all slices. |
| `right-click` | Open the menu acting on the selected slices. |

Press the modifier keys before drawing the rectangle, or they won't take effect.

## Editing

| Shortcut | Action |
|---|---|
| `ctrl + Z` | Undo the last action. |
| `ctrl + shift + Z` or `ctrl + Y` | Redo the last undone action. |
| `drag a slice handle` | In positioning mode, move the selected slices along the slicing axis. |
| `D` | In positioning mode, distribute the selected slices evenly between key slices. |
| `O` | In positioning mode, change the overlap mode. |

## Registrations

| Shortcut | Action |
|---|---|
| `P` | View the previous registration step of the slices. |
| `N` | View the next registration step of the slices. |

## Other

| Shortcut | Action |
|---|---|
| `K` | Print all the key bindings of the ABBA window in the Fiji console. |

## BigWarp

When a registration is edited in [BigWarp](https://imagej.net/plugins/bigwarp):

| Shortcut | Action |
|---|---|
| `space` | Toggle the landmark mode. |
| `ctrl + left-click` | Pin a new landmark on both the fixed (atlas) and the moving (slice) image. |
| `drag + left-click` | In landmark mode, drag an existing landmark. |
| `F` | Toggle the display of the fused transformed and fixed images. |
| `T` | Toggle the transformation of the image. |

See the [BigWarp documentation](https://imagej.net/plugins/bigwarp) for all its commands.
